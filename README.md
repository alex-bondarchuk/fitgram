# FitGram — фітнес-трекер як Telegram Mini App

Застосунок відкривається на **головному меню**: звідти обираєте один із чотирьох розділів або натискаєте **«Відправити звіт»**.

Розділи:

1. **Раціон** — 8 категорій продуктів (А–Ж), для кожної задається ліміт ккал на добу; додаток рахує, скільки грамів кожного продукту можна з’їсти, а при внесенні продукту (повзунок або ручне введення) перераховує залишок для решти. Можна додавати свої продукти. Підсумок: білки, калорії, жири, вуглеводи.
2. **Кроки** — запис кроків, кільце прогресу, відстань, 7-денний графік.
3. **Тренування** — тип, тривалість, калорії (авто за MET), нотатки; підсумок за тиждень.
4. **Заміри** — вага, обхват плеча, грудей, талії та стегон: згорнута форма запису, міні-графіки за останні 6 записів і історія. Заміри робляться раз на тиждень, вранці в неділю: після 04:00 неділі на головній біля «Заміри» світиться червона крапка, доки не буде запису.
5. **Профіль** — стать, вік, зріст, вага, активність, ціль; ІМТ, базовий обмін, рекомендовані калорії/БЖУ; графік ваги; щоденні цілі.

Дані зберігаються в `localStorage` і додатково синхронізуються через Telegram CloudStorage (між пристроями) — окремо для кожного акаунта Telegram. Для керування доступом і відправки звіту потрібен невеликий Cloudflare Worker (див. нижче).

## Локальний запуск

```bash
python -m http.server 5173
```

Відкрийте http://localhost:5173 — у браузері все працює і без Telegram.

## Підключення до Telegram

Mini App потребує **HTTPS**-адреси. Найпростіше — безкоштовний хостинг статики (GitHub Pages, Netlify, Cloudflare Pages, Vercel): завантажте файли `index.html`, `style.css`, `app.js`.

Потім у [@BotFather](https://t.me/BotFather):

1. `/newbot` — створіть бота (якщо ще немає).
2. `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button** → вставте HTTPS-URL і назву кнопки (наприклад, «FitGram»).

Тепер у чаті з ботом поруч із полем вводу з’явиться кнопка, що запускає застосунок. Альтернатива — `/newapp`, щоб отримати пряме посилання `t.me/<бот>/<app>`.

## Багато користувачів і підтвердження доступу

Кожен користувач Telegram має **власні дані**: вони прив’язані до його Telegram ID (локально — ключ `fitgram_v1_<ID>`, у хмарі — Telegram CloudStorage акаунта).

Доступ закритий: хто вперше відкриває бота (`/start`) або застосунок, бачить екран «Очікуємо підтвердження», а **вам (розробнику) в чат із ботом приходить запит** з іменем, @username та ID і кнопками «✅ Додати» / «❌ Відхилити». Після «Додати» користувачеві приходить повідомлення з кнопкою «Відкрити FitGram», а застосунок на екрані очікування запускається сам.
Команда `/users` у чаті з ботом показує всіх, з кнопками «Додати», «Відхилити», «Вилучити» (доступ можна закрити будь-коли).

Це забезпечує Cloudflare Worker (`worker/worker.js`): він перевіряє підпис Telegram, веде список користувачів у KV-сховищі, приймає кнопки через webhook і пересилає звіти. Він же дає змогу кнопці «Відправити звіт» писати від імені бота (токен не можна зберігати в публічному коді).

> Коду застосунку (GitHub Pages) це не ховає: сторінка публічна, але без підтвердження вона показує лише екран очікування, а звіти й дані Telegram недоступні. Поза Telegram (у звичайному браузері) застосунок не запускається.

### Налаштування (один раз)

1. https://dash.cloudflare.com → **Workers & Pages** → створіть Worker `fitgram-report` (якщо вже є — відкрийте його) → **Edit code** → замініть вміст кодом із `worker/worker.js` → **Deploy**.
2. **KV-сховище:** у меню Cloudflare **Storage & Databases → KV → Create** (назва довільна, напр. `fitgram-users`). Потім у Worker-і: **Settings → Bindings → Add → KV namespace**, назва змінної **`USERS`**, оберіть створене сховище → **Deploy**.
3. **Settings → Variables and Secrets** → додайте:
   - `BOT_TOKEN` — **Secret**, токен бота від @BotFather (вже є);
   - `WEBHOOK_SECRET` — **Secret**, вигадайте довгий пароль лише з латинських літер, цифр, `_` та `-` (напр. `Fg_k39sLq0Zx7vWm2PaR`);
   - `ADMIN_ID` — **Text**, ваш Telegram ID (див. крок 5);
   - `ALLOWED_ORIGIN` — Text, `https://alex-bondarchuk.github.io` (бажано; вже є).
4. **Підключіть webhook:** відкрийте в браузері `https://fitgram-report.<акаунт>.workers.dev/setup?key=<WEBHOOK_SECRET>`. Має з’явитися `"webhook": "ok"`, `"kvBound": true`, `"adminIdSet": true`.
5. **Як дізнатися свій ID:** до кроку 4 додайте тільки `WEBHOOK_SECRET`, відкрийте `/setup?key=…`, напишіть боту `/myid` — він відповість вашим ID. Вставте його в `ADMIN_ID`, збережіть (**Deploy**) і ще раз відкрийте `/setup?key=…` (щоб з’явилась команда `/users`).
6. Напишіть боту `/start` — ви побачите «Ви адміністратор». Адміністратор має відкритий доступ завжди, без запиту.
7. `config.js` → `reportUrl` — адреса Worker-а (вже вписана).

Знайомим достатньо дати посилання на бота. Вони натискають **Start**, ви отримуєте запит і додаєте їх кнопкою. Незнайомі користувачі, яких ви відхилили, більше вас не турбують.

Поки `reportUrl` порожній, кнопка показує текст звіту з кнопкою «Скопіювати».
